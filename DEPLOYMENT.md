# Deployment notes

The site is a static front-end. Enable GitHub Pages in repository Settings > Pages and select GitHub Actions as the deployment source. The workflow in .github/workflows/pages.yml deploys the root directory on pushes to main.

The five review cards are placeholders because the supplied business plan states that the studio had no reviews yet. Replace them only with genuine customer feedback approved for publication.

Live payment processing, secure customer authentication, shared booking availability, server-side data storage, email/SMS notifications and private cloud galleries require backend services. Booking CTAs currently open an email inquiry.
